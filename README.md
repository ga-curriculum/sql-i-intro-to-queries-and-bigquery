## About
An introduction to SQL, from foundational concepts to slightly more advanced techniques, using Google BigQuery as the practical platform.

This module covers what relational databases are, the set up of BigQuery, and basic SQL queries, ordering and aliasing, as well as basic aggregations.


## Learning Objectives

*You will be able to:*

- Explain what SQL is.
- Use Google BigQuery to access data via SQL.
- Write and execute a SQL query, including `SELECT`, `FROM`, `LIMIT`, and `DISTINCT`.
- Order data using `ORDER BY`.
- Alias tables in SQL using `AS`.
- Practice writing aggregate functions: `MIN`, `MAX`, `SUM`, `AVG`, and `COUNT`.
- Understand the order of operations in SQL.
